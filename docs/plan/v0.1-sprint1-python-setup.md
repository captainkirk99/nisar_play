# v0.1 Sprint 1 Plan: Python Setup

## Sprint Goal and Scope

Establish a reproducible Python environment for the NISAR data exploration
project so that NISAR netCDF4/HDF5 products can be read in Python. Scope is
environment setup and read-readiness only — reading and plotting the soil
moisture data itself is Sprint 2.

Target data file:
`data/NISAR_L3_PR_SME2_028_005_A_020_4005_DHDH_A_20260813T125218_20260813T125253_P05023_N_F_J_001.h5`

## Clarified Decisions

- **Environment:** venv + `pyproject.toml` (TOML project file; roadmap
  wording updated from "yaml")
- **Reader stack:** xarray with the netCDF4 engine
- **Plotting deps:** matplotlib + cartopy installed now, ahead of Sprint 2
  (SME2 is posted on EASE-Grid 2.0, so projection support will be needed)
- **Verification:** pytest smoke test opening the sample SME2 file

## Major Tasks (dependency order)

1. Create `pyproject.toml` declaring the project (name, Python version) and
   dependencies: `xarray`, `netCDF4`, `matplotlib`, `cartopy`; dev
   dependency: `pytest`.
2. Create a venv (`python -m venv .venv`) and install the project into it
   (`pip install -e .[dev]` or equivalent).
3. Add `.gitignore` entries for `.venv/`, `__pycache__/`, etc. (create
   `.gitignore` if missing).
4. Create a minimal package under `src/` (e.g. `src/nisar_play/__init__.py`)
   so the project is installable and importable.
5. Add `tests/test_read_sme2.py`: a pytest smoke test that opens the sample
   `.h5` with xarray/netCDF4 and asserts expected top-level groups and the
   soil moisture dataset path exist.
6. Run pytest in the venv and confirm the smoke test passes.
7. Update documentation (see below).

## Acceptance Criteria

- A fresh clone can create the venv and install all dependencies from
  `pyproject.toml` alone.
- `import xarray, netCDF4, matplotlib, cartopy` succeeds inside the venv.
- The pytest smoke test opens the sample SME2 file and passes.

## Testing Requirements

- pytest smoke test (new capability: reading NISAR netCDF4/HDF5) that:
  - opens the sample SME2 `.h5` file,
  - asserts expected HDF5 group structure (e.g. `/science/LSAR/SME2/...`),
  - asserts the soil moisture dataset is present and non-empty.
- `pytest` runs cleanly from the project root inside the venv.
