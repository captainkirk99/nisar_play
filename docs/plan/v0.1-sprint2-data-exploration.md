# v0.1 Sprint 2 Plan: Data Exploration

## Sprint Goal and Scope

Read the sample NISAR SME2 (Level 3 Soil Moisture) product and produce two
figures: (1) a projection-aware soil moisture map and (2) a footprint
overview map showing the granule's lat/lon bounds. Code lives in reusable
modules under `src/nisar_play/` with a CLI entry point; figures are saved
as PNGs to an untracked `output/` directory.

Target data file:
`data/NISAR_L3_PR_SME2_028_005_A_020_4005_DHDH_A_20260813T125218_20260813T125253_P05023_N_F_J_001.h5`

Implements requirements **R3** (plot soil moisture) and **R4** (plot
lat/lon bounds); builds on the Sprint 1 environment (R1, R2).

## Clarified Decisions

- **Deliverable:** module(s) in `src/nisar_play/` (reader + plotting
  functions) plus a small CLI/script entry point.
- **Soil moisture map:** cartopy GeoAxes with proper projection handling of
  the EASE-Grid 2.0 data, with coastlines and gridlines.
- **Lat/lon bounds:** separate footprint overview map showing the data
  bounding box on a regional map with coastlines.
- **Figures:** saved to PNG in untracked `output/`; option to also display
  interactively.
- **Masking:** mask soil moisture using `retrievalQualityFlag` and/or fill
  values so only valid retrievals are shown; do not plot ancillary layers.
- **Testing:** pytest unit tests for reader functions plus plot smoke tests
  using the Agg backend asserting a figure/PNG is produced; no
  image-comparison tests.

## Major Tasks (dependency order)

1. **Reader module** (`src/nisar_play/sme2.py` or similar):
   - Open the SME2 `grids` group with xarray (netCDF4 engine), following
     the pattern in `tests/test_read_sme2.py`.
   - Expose functions to load soil moisture (with quality/fill masking
     applied), lat/lon coordinates, and the granule's lat/lon bounds.
   - Read useful metadata (units, projection/EASE-Grid 2.0 attributes)
     for plot labeling.
2. **Plotting module** (`src/nisar_play/plots.py` or similar):
   - Soil moisture map: cartopy GeoAxes, EASE-Grid 2.0-aware
     georeferencing (native CRS or lat/lon via `transform=`), coastlines,
     gridlines, colorbar with units.
   - Footprint overview map: bounding box of the granule drawn on a
     regional cartopy map with coastlines, extent padded around the box.
   - Both functions save PNG to a configurable output directory and
     optionally show interactively.
3. **CLI entry point** (e.g. `python -m nisar_play` or console script in
   `pyproject.toml`): takes the `.h5` path (default: the sample file in
   `data/`), produces both figures into `output/`.
4. **Housekeeping:** add `output/` to `.gitignore`.
5. **Tests** (see below), run via `.venv/bin/pytest`.
6. **Documentation updates** (see below).

## Acceptance Criteria

- Reader functions return masked soil moisture, coordinates, and lat/lon
  bounds from the sample file.
- Running the CLI produces two PNGs in `output/`: a soil moisture map
  (coastlines, gridlines, colorbar with units, only valid retrievals
  shown) and a footprint overview map (bounding box on a regional map).
- All new code has docstrings; all tests pass.

## Testing Requirements

- Unit tests for reader functions: masking removes fill/flagged values,
  values lie in a plausible soil moisture range, bounds match the
  lat/lon arrays' min/max.
- Plot smoke tests (matplotlib Agg backend): each plotting function runs
  without error and writes a non-trivial PNG file (exists, size > 0).
- CLI smoke test: invoking the entry point produces both expected PNGs.
- No pixel/image-comparison tests.
- Existing Sprint 1 tests continue to pass.
