# Version 0.1 — NISAR SME2 Soil Moisture Exploration

> First release: a reproducible Python environment for reading and plotting
> NISAR Level 3 Soil Moisture (SME2) products, with tests, CI, and a
> published documentation site.

## Highlights

- **Reproducible Python environment** (#1) — venv + `pyproject.toml`
  (setuptools, `src/` layout) with the full xarray/netCDF4/matplotlib/cartopy
  stack.
- **SME2 reader and plotting library** (#2) — quality-masked soil moisture
  grids and lat/lon bounds from NISAR SME2 HDF5 files, plotted on
  projection-aware cartopy maps.
- **`plot-sme2` CLI** (#2) — one command produces the soil moisture map and
  footprint overview PNGs.
- **Published documentation site** (#3) — MkDocs (Material) + mkdocstrings
  API reference, deployed to GitHub Pages on pushes to `main`.
- **CI gating merges** (#5) — pytest + strict docs build on every PR, with a
  synthetic SME2 fixture so tests run without the 119 MB sample granule.

## Features

### Data Reading
- **SME2 reader module** (#2, PR #4) — `src/nisar_play/sme2.py`: opens the
  `/science/LSAR/SME2/grids` group with xarray (netCDF4 engine); loads soil
  moisture with fill values masked to NaN and pixels flagged "not
  recommended" by `retrievalQualityFlag` removed; computes granule lon/lat
  bounds and discovers sample files by NISAR naming convention.

### Visualization
- **Soil moisture map** (#2, PR #4) — `src/nisar_play/plots.py`: cartopy
  GeoAxes with coastlines, state borders, gridline labels, and a
  units-labeled colorbar; EASE-Grid 2.0 data drawn via 1-D lat/lon
  coordinates.
- **Footprint overview map** (#2, PR #4) — the granule's bounding box on a
  padded regional map with coastlines.
- **CLI entry point** (#2, PR #4) — `plot-sme2` (also `python -m
  nisar_play`) writes both PNGs to an untracked `output/` directory, with
  optional interactive display.

## Bug Fixes

None — initial release.

## Environment

- venv-based setup with all dependencies declared in `pyproject.toml`;
  install with `pip install -e ".[dev]"` (#1).
- Optional-dependency groups: `dev` (pytest) and `docs` (MkDocs stack) (#1, #3).

## Testing

- `tests/test_read_sme2.py` (#1) — smoke tests for the SME2 HDF5 group
  structure, soil moisture data, and coordinates.
- `tests/test_plots_sme2.py` (#2) — reader unit tests (masking, coordinates,
  bounds), plot smoke tests on the Agg backend, and a CLI test producing
  both PNGs.
- `tests/conftest.py` (#5, PR #6) — session-scoped fixture that generates a
  small synthetic SME2-like HDF5 file when the real granule is absent
  (`NISAR_PLAY_FORCE_SYNTHETIC=1` forces it locally).
- CI workflow `.github/workflows/ci.yml` (#5, PR #6) — runs `pytest` and
  `mkdocs build --strict` on PRs targeting `main` and pushes to `main`
  (Python 3.12), with pip and cartopy Natural Earth caching; documented
  branch protection gates merges on the `test` check.

## Known Limitations

- The 119 MB sample SME2 granule is untracked; real-data tests only run
  where it is present locally (CI uses the synthetic fixture).
- Only the L3 SME2 product is supported; other NISAR product types (RSLC,
  GCOV, GUNW, ...) are not yet handled.
- Branch protection on `main` is a manual repository-settings step.
- The sample granule is BETA/PROVISIONAL-era data; calibration caveats
  apply (see the NISAR Data User Guide).
